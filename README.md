## 🛠️ Troubleshooting

| Problem | Solution |
|---|---|
| Setup file blocked by SmartScreen | Click **More info**, then **Run anyway**. |
| Installer closes right after launch | Restart Windows, then run the setup file again from a local folder instead of a network drive. |
| App opens with a blank window | Update your graphics driver and confirm DirectX 11 or newer is available. |
| PDF pages render slowly | Close other heavy applications and check that the document is stored on a local disk. |
| OCR returns empty results | Confirm the scanned page is at least 200 DPI and set the correct document language. |
| Printing produces missing text | Use a PDF printer driver or update the printer driver from the manufacturer page. |
| Settings do not persist after closing | Check that your Windows user profile has write access to the Documents folder. |
